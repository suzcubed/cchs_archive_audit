# Culver City Historical Society Archive Audit

## Overview

An audit of the Culver City Historical Society (CCHS) archive database to improve data quality, cataloging consistency, and searchability.

[Read the full project case study (PDF)](CCHS_Audit_Case_Study.pdf)

## Objectives

- Audit the existing archive database and identify inconsistencies in record categories.
- Clean and consolidate the existing category vocabulary.
- Develop controlled object type and subject taxonomies.
- Improve database searchability and support interoperability of archival records.

## Methods

- **Data cleaning:** Used OpenRefine to identify and consolidate duplicate and low-count categories.
- **Taxonomy design:** Used the cleaned data to develop an object type taxonomy in collaboration with the archive team.
- **Manual audit:** Reviewed and reassigned archive records in Google Sheets to align with the new taxonomy.
- **Database implementation:** Added validated Object Type and Subject fields in FileMaker to support consistent cataloging.

## Results

- Reduced the object type taxonomy from 384 categories to 54 agreed-upon terms.
- Separated object type and subject into distinct fields.
- Created a taxonomy definitions document with definitions and examples for catalogers.
- Added validated fields in FileMaker to support future cataloging consistency.
- Established an initial subject taxonomy of 33 terms for further testing and refinement.
